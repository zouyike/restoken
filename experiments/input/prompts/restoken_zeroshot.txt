## Property Definitions

- **Class**: Functional analog of the canonical amino acid this block resembles (G=Gly, A=Ala, V=Val, L=Leu, I=Ile, F=Phe, P=Pro, S=Ser, T=Thr, K=Lys, D=Asp, E=Glu, C=Cys, H=His, Y=Tyr, N=Asn, Q=Gln, R=Arg, W=Trp, M=Met, ncaa=no canonical analog)
- **Chiral**: Stereochemistry (L / D / A=achiral)
- **Charge**: Net charge label (neu=neutral / pos=+1 / neg=-1)
- **Backbone**: Main chain type (alpha / beta / gamma)
- **N-mod**: N-terminal modification (NO=none / NCY=N-cyclic/proline-like / NME=N-methyl)
- **Bulk**: Side chain bulk (small / med / large)
- **Polarity**: Side chain polarity (low / med / high)
- **Flexibility**: Rotatable bonds (low / med / high)
